Hướng dẫn sử dụng

Tạo project Giỏ hàng, ghi một bài test và chạy lại với dữ liệu của từng môi trường.

Trong trang này Tạo project đầu tiên Dataset môi trường Ghi và sửa test script Chỉnh TypeScript và gắn biến Chạy và xem kết quả Quản lý và sao lưu

Tạo project đầu tiên

  1. Ở màn hình trống, nhập Tên project, ví dụ Giỏ hàng.
  2. Điền Website URL mặc định nếu đã có địa chỉ web. Studio dùng địa chỉ này để gợi ý URL khi tạo script.
  3. Bấm Tạo project. Sau đó chọn project ở sidebar. Dùng nút + hoặc Tạo project để tạo thêm.

Dataset môi trường

  1. Trong project, mở Dataset / .env, bấm Thêm môi trường và đặt tên staging.
  2. Thêm BASE_URL là URL HTTP/HTTPS đầy đủ, rồi dùng Thêm biến để thêm QUANTITY và EXPECTED_TOTAL. Có thể dùng Import .env để thay bảng biến đang soạn bằng nội dung file.
  3. Bấm Lưu dataset. Studio chọn môi trường vừa lưu. Lặp lại cho production với cùng tên biến và giá trị phù hợp, rồi dùng menu Môi trường chạy để đổi dataset trước khi ghi hoặc chạy test.

Mặc định dùng dataset mặc định của project khi đã có. Studio tạo hoặc dùng lại dataset default trong lần đầu ghi với lựa chọn này. Bạn có thể mở dataset đó để sửa giá trị.

Ghi và sửa test script

  1. Bấm Tạo test script, nhập tên và Website URL, kiểm tra môi trường rồi chọn Bắt đầu ghi thao tác. Hủy hoặc dấu × đóng form.
  2. Trong Browser Desktop, mở giỏ hàng và đổi số lượng. Trong Playwright Inspector, chọn assertion văn bản rồi bấm vào tổng tiền. Bạn cũng có thể kiểm tra phần tử hiển thị hoặc giá trị trong ô nhập. Nếu cần quay lại tab ghi, bấm Browser Desktop trong thanh phiên ở Manager.
  3. Bấm Tạm dừng để sửa và chỉnh hoặc xóa dòng TypeScript bị sai. Nếu thao tác sai làm web chuyển trang, đưa web về đúng trạng thái trong lúc tạm dừng.
  4. Bấm Áp dụng và ghi tiếp. Inspector cập nhật bản TypeScript, trình sửa ẩn và các thao tác mới được nối vào sau phần đã sửa.
  5. Lưu test script lưu bản cuối và đóng tab. Hủy test script hỏi xác nhận rồi bỏ bản nháp và đóng tab. Khi ghi thay bản cũ, bản đã lưu được giữ nếu bạn hủy phiên.

Chỉnh TypeScript và gắn biến

  1. Bấm tên script hoặc chọn Xem nội dung trong menu ···. Chọn Chỉnh sửa để mở editor.
  2. Bôi đen giá trị cần thay, chọn biến QUANTITY rồi bấm Gắn biến. Studio dùng dữ liệu môi trường lúc chạy, ví dụ data("QUANTITY").
  3. Dùng Chuyển URL website sang BASE_URL để chuyển URL cùng website sang địa chỉ của môi trường chạy. Bấm Lưu script hoặc Hủy sửa. Dùng Tải file .ts để tải bản script.

Chạy và xem kết quả

  1. Chọn Môi trường chạy. Bấm Chạy trong UI ở một hàng, hoặc tick một số hàng rồi chọn Chạy nhóm trong UI. All (toàn project) chọn toàn bộ script. Bỏ chọn xóa lựa chọn.
  2. Playwright UI mở tab riêng, chọn đúng file và môi trường rồi chạy test. Bấm test để xem từng bước. Với lỗi assertion, mở bước lỗi rồi chọn tab Errors để xem giá trị Expected và Received, cùng ảnh chụp trạng thái trang ở bước đó nếu có.
  3. Sửa script hoặc dataset, rồi chạy lại. Để đổi môi trường, quay về Manager, chọn môi trường khác và mở lại Playwright UI.

Quản lý và sao lưu

  • Tìm test script lọc danh sách. Menu sắp xếp có Mới cập nhật và Tên A–Z.
  • Trong menu ···, dùng Copy sang project, Ghi lại script hoặc Xóa test script. Bạn cũng có thể copy nhiều script bằng thanh chọn nhóm. Bản copy dùng dataset của project đích. Khi trùng file, Studio yêu cầu xác nhận ghi đè.
  • Trên thanh project, dùng Đổi tên project, Clone project hoặc biểu tượng Xóa project. Khi clone, chọn có sao chép dataset hay không. Sau khi đổi tên, mở lại tab Playwright UI từ Manager.
  • Mở Cài đặt sao lưu để xem trạng thái, thời điểm hoặc lỗi sao lưu. Bấm Sao lưu ngay để thử lại. Bản sao local nằm trong tests-scripts/<tên-project>/.
