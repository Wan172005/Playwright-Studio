Sao lưu
File test script được sao lưu tự động vào tests-scripts/<tên-project>/ ngay trong folder ứng dụng. Script gốc vẫn nằm trong volume; các snapshot có phiên bản tiếp tục được giữ riêng.
Bản sao local cập nhật theo lần lưu mới nhất. Khi xóa script hoặc project, các file local đã sao lưu và snapshot cũ vẫn được giữ.
